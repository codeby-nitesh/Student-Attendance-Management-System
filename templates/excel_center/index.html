Excel File Storage Architecture & Multi-User Synchronization

All institutional application records are directly stored inside pure OpenPyXL/Pandas Excel workbooks (data/*.xlsx). To ensure strict enterprise-grade integrity, safe file operations are enforced via an re-entrant file lock (threading.RLock) and atomic write-replace buffers that guard against sudden power cuts, partial writes, or concurrent file access collisions.

Automatic timestamped backups are generated inside backups/ prior to every major transactional write.
